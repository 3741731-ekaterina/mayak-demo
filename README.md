# Учебный табель «Маяк»

[Открыть демо](https://uchebny-tabel-mayak.vercel.app/)

Выберите роль бригадира, заполните часы и отправьте табель на согласование. Выйдите и войдите как руководитель объекта, чтобы утвердить запись. Для просмотра начислений выберите администратора.

Все данные вымышлены. Изменения сохраняются в браузере участника. Для смены роли используйте тот же браузер.
